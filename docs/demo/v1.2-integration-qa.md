# V1.2 Integration QA Report

## Summary
V1.2 introduces data persistence, audit trails, and configurable sandbox rules. This report confirms that the system maintains high integrity across the "event-to-action" loop while supporting new observability features.

## Test Results

### 1. Data Persistence (Prisma)
- [x] `AfterSalesCase` persists with `merchantId` and `channel`.
- [x] `CaseMessage` records inbound and outbound messages correctly.
- [x] `CaseAction` tracks mock executions (success/pending).
- [x] `NormalizedChannelEvent` archived for replay capability.

### 2. Audit Trail Observability
- [x] `AuditLog` captures `event_received`.
- [x] `AuditLog` captures `category_decision`.
- [x] `AuditLog` captures `risk_decision`.
- [x] `AuditLog` captures `action_executed`.
- [x] UI successfully renders audit timeline in the sidebar.

### 3. Configurable Sandbox Rules
- [x] Default rules loaded when DB is empty.
- [x] `couponCompensationLimit` correctly shifts low-risk compensation to medium-risk when exceeded.
- [x] `highRiskKeywords` successfully trigger `complaint_escalation` or `human_takeover`.

### 4. Commercial Adapters
- [x] `MockTaobaoAdapter` and `MockDouyinAdapter` receive correct `orderId` and parameters.
- [x] `ActionService` selects correct adapter based on action channel.

### 5. Frontend Integration
- [x] `fetchCases` retrieves live data from the API.
- [x] `mapApiCaseToUiCase` handles status mapping for the operator queue.
- [x] Fallback fixture used gracefully if API is offline.

## Performance & Layout
- API response time for complex classification: < 100ms (Mocked).
- UI render performance: High (GSAP animations smooth, no cascading effect warnings).
- Layout verified across 1366, 1920, and mobile widths.
